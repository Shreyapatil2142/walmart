# 🛒 Walmart Smart Inventory Management System

## 📊 Overview

The **Smart Inventory Management System** is a web-based dashboard designed to efficiently manage inventory, track sales, and identify dead stock across multiple stores.

It provides real-time insights to help businesses make smarter decisions and optimize stock management.

---

## 🚀 Features

### 📌 Dashboard

* Overview of total products and stores
* Real-time inventory statistics
* Last updated timestamp

### 📦 Inventory Management

* Track available products
* Monitor stock levels
* Identify low stock items

### 💰 Sales Tracking

* Analyze sales trends over time
* Visual representation of sales data

### 🧊 Dead Inventory Detection

* Identify unsold or inactive products
* Reduce inventory waste

### 🔥 Analytics & Visualization

* 📈 Sales Trend Graph
* 🌍 Inventory Heatmap

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```

---

### 2️⃣ Install dependencies

#### Frontend

```bash
cd frontend
npm install
npm run dev
```

#### Backend

```bash
cd backend
npm install
npm start
```

---

### 3️⃣ Environment Variables

Create a `.env` file in backend:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```
